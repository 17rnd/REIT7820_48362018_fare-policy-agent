# Project Idea

## Working Title

An MCP-Based Public Transport Fare Policy Scenario Analysis Agent

## Project Purpose

This project aims to develop an MCP-compatible agent for evaluating
public transport fare-policy scenarios.

## Main Problem

Fare changes may influence public transport patronage and fare revenue.
The agent will provide reproducible scenario analysis based on baseline
fare, baseline patronage, fare changes and fare-elasticity assumptions.

## Expected Inputs

- Baseline fare
- Baseline patronage
- Fare-change percentage
- Fare elasticity
- Passenger type
- Time period
- Fare structure

## Expected Outputs

- New fare
- Estimated patronage
- Estimated revenue
- Percentage changes
- Assumptions
- Limitations

## Initial Scope

The first version will focus on deterministic fare-policy scenario
analysis and elasticity sensitivity analysis.

## Out of Scope

- Real-time route planning
- Individual passenger prediction
- Full causal inference
- Deep-learning models
